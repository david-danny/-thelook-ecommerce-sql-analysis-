## Suggested LinkedIn Post

I have published a new SQL portfolio project: **TheLook E-commerce Performance & Customer Analysis**.

Using Google BigQuery and the public TheLook Ecommerce dataset, I analyzed six business questions:

- monthly sales, buyer, order, and AOV trends;
- top-performing categories in 2024;
- products priced furthest above their category average;
- first versus repeat purchase contribution;
- returned sales and return rates by category; and
- customer health by country using recency buckets.

One of my main takeaways was that a useful analysis must go beyond reporting numbers. For example, a high category return rate and a high returned sales amount require different operational responses, while a large price gap versus a category average is a signal for investigation rather than proof that a product is overpriced.

This project demonstrates my use of joins, CTEs, window functions, conditional logic, date functions, and Looker Studio, together with the business reasoning behind each query.

## 60-Second Interview Explanation

“I used BigQuery to analyze six connected problems for a fictional fashion retailer: growth, category performance, pricing, repeat purchasing, returns, and customer health. I first translated each business question into a clear metric definition, then used joins, CTEs, window functions, and date logic to build the analysis. The most useful part was separating observations from decisions. For example, first purchases made up 63.8% of orders, but I would not move budget based on that share alone; I would also compare AOV, revenue, retention cost, and lifetime value. Similarly, I separated categories with high return rates from those with high returned value because they need different interventions. I documented those assumptions and limitations in the repository so another analyst can understand and rerun the work.”
